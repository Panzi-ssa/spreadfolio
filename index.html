数据仓库（私有）

代码可以公开，持仓放一个私有仓库里。页面用 token 通过 GitHub API 读写它，别人看不到金额。

危险操作

清空本机的持仓、交易、入金记录（云端私有仓库不动，需要的话清完再同步一次覆盖）。

本地备份

换手机时：先导出 JSON 传过去导入，或配置好 GitHub 直接拉取。建议只在一台设备开「自动同步」，避免多端互相覆盖。
